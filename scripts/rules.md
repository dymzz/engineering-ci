# 原则规则

- 按功能拆分脚本：gh_workflow_artifacts.py 负责一次性触发、等待、日志获取和断点恢复。需要持续运行的监控功能，单独编写脚本，不强行合并到 ghwf。
- 允许成熟第三方库：例如 tenacity 处理重试、platformdirs 管理缓存路径。只有实际需要时引入，不必坚持 Python 标准库。
- 避免重复实现：GitHub 认证、Workflow 调度和 Artifact 下载继续优先使用 gh。多个脚本确实存在重复逻辑时，再提取共享模块。
- 按需决定是否常驻：定期任务优先使用 GitHub Actions Schedule 或系统任务计划；确实需要持续监听的功能才采用独立常驻进程。
- 不提前建设框架：暂时不引入统一服务管理器、消息队列或数据库。
